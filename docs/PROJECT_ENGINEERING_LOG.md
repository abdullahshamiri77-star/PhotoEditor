# PhotoEditor — سجل الذاكرة الهندسية

> هذه الوثيقة هي سجل الاستمرارية للمشروع. تُحدّث مع كل مرحلة؛ لا تُحذف القرارات السابقة بل تُضاف لها مراجعات مؤرخة.

## الهدف والمعيار
بناء محرر صور Android متعدد الطبقات حقيقي، بمستوى هندسي يليق بمنافسة المحررات الاحترافية. لا تُعد الواجهة أو ظهور الزر دليلاً على اكتمال الميزة.

## قواعد العمل الثابتة
1. التطوير على فرع موحد: `integration/multilayer-editor-mainline`.
2. كل تغيير يبدأ من أحدث HEAD موثّق.
3. لا دمج إلى main قبل نجاح الاختبارات والبناء ومراجعة التغيير.
4. لا حذف لميزة قائمة قبل حصرها وضمان بديل مكافئ واختباره.
5. كل ميزة لها بطاقة تحقق: واجهة، منطق فعلي، ربط بالمستند والمحرك، الطبقة المستهدفة، lock/visibility، undo/redo، اختبارات، اختبار جهاز.
6. نفصل بين: كتابة الكود، نجاح الاختبارات، نجاح بناء APK، الدمج، وقبول الجهاز.
7. عند كل جلسة نسجل آخر commit وحالة CI والقرار التالي والمخاطر المفتوحة.
8. لا نغيّر اختباراً لإخفاء عطل، ولا نعلن النجاح قبل الدليل.

- compositor الحالي يرسم طبقات bitmap فقط.
